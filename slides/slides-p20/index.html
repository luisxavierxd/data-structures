20.1 The idea

Groups that never overlap.

20.1 · The idea

Every element is in exactly one group

  • Disjoint sets: groups that share no elements.
  • find(x): which group is x in? It returns the group's name.
  • union(a, b): join the group of a and the group of b.
  • Same group? Check find(a) == find(b).

Adapted from de la Cueva et al. (2020), Fig. 11.4.

20.1 · The idea

Start alone, then merge

Groups only grow: we never split them. Weiss (2014), § 8.2.

Checkpoint

Elements 0 to 5 start alone. Then: union(0, 1), union(2, 3), union(4, 5), union(1, 3). How many groups are left?

B. Correct. union(1, 3) joins the group of 1 with the group of 3: {0, 1} and {2, 3} become one.

A. Each union joins two groups into one: 6 − 4 = 2 groups, not 4.

C. union(1, 3) joins whole groups, not only 1 and 3.

20.2 · A forest in one array

20.2 · A forest in one array

Careless unions build a line

  • union is O(1), but find costs the depth of the node.
  • The fix: keep the trees short. That is 20.3.
Checkpoint

This is the array s of a disjoint set. What does find(7) return?

C. Correct. find climbs parents until a negative value: 7 → 6 → 4. The root 4 names the group.

A. 6 is only the first step. find keeps climbing until it reaches a root.

B. −5 is the value stored at the root. find returns the root itself: 4.

20.3 Two fixes

Keep the trees short.

20.3 · Two fixes

Fix 1: the smaller tree hangs under the larger

  • The root stores its size as a negative number: s[4] = −5.
  • With union by size, no node is deeper than log₂ N.

Weiss (2014), § 8.4, Fig. 8.10–8.11. Union by height (rank) works just as well.

20.3 · Two fixes

Fix 2: find flattens the path it walks

This is path compression. Weiss (2014), § 8.5.

20.3 · Two fixes

The class and find: one line does the compression


class DisjSets {
    std::vector<int> s;     // s[i]: parent of i, or -size if i is a root
public:
    DisjSets(int n) : s(n, -1) {}   // n groups of one element
    int find(int x);
    void unionSets(int a, int b);
};
      

int DisjSets::find(int x) {
    if (s[x] < 0)
        return x;                    // x is a root: the name of its group
    return s[x] = find(s[x]);        // path compression
}
20.3 · Two fixes

unionSets: compare sizes, then hang


void DisjSets::unionSets(int a, int b) {
    int ra = find(a);
    int rb = find(b);
    if (ra == rb)
        return;                      // already in the same group
    if (s[ra] > s[rb])               // ra is smaller (sizes are negative)
        std::swap(ra, rb);
    s[ra] += s[rb];                  // the sizes add up
    s[rb] = ra;                      // smaller tree hangs under the larger
}

Weiss names it unionSets because union is a C++ keyword.

20.3 · Two fixes

Both fixes together: almost O(1)

Versionfind, worst case
Careless unionO(N)
Union by sizeO(log N)
Union by size + path compressionalmost O(1) per operation
  • "Almost": the extra factor is at most 5 for any real N.

The proof is long: Weiss (2014), § 8.6; Cormen et al. (2022), § 19.4.

Checkpoint

With union by size, you join a group of 5 elements and a group of 2. What happens?

A. Correct. The smaller tree goes under the larger, and the sizes add up: −5 + −2 = −7.

B. Backwards: that makes 5 nodes one level deeper instead of 2.

C. The new root must store the new size, or the next union compares the wrong sizes.

Self-study

Two more places you will meet union-find

  • Mazes: knock down random walls between cells.
  • Knock a wall only if its two cells are not connected yet.
  • Kruskal's algorithm: the cheapest way to connect a graph.
  • It takes the cheapest edges first and skips edges that close a cycle.

Mazes: Weiss (2014), § 8.7. Kruskal: Weiss (2014), § 9.5.2; you will see it in an algorithms course.
